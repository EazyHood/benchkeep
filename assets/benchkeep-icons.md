# Benchkeep icon assets

Original vector mark drawn for Benchkeep: a burnt-orange location bookmark with a dark embroidery needle and cream thread. It connects the product's visual bookmark with its craft use case. No third-party logo, stock image, or generated-photo edit was used.

Palette: cream `#F5F0E7`, burnt orange `#BA4F2A`, ink `#262F2B`.

- `benchkeep-icon.svg` / `benchkeep-icon.png`: opaque 1024 × 1024 app icon.
- `benchkeep-adaptive-foreground.svg` / `.png`: transparent 1024 × 1024 adaptive foreground, mark scaled to preserve space around common masks.
- `benchkeep-adaptive-monochrome.svg` / `.png`: monochrome adaptive icon layer.
- `benchkeep-favicon.png`: 64 × 64.

SVGs are the editable source. PNGs were rendered locally using the Codex bundled Sharp runtime; the app dependency manifest was not changed for rendering. The full-colour master PNG was visually inspected. Final device icon masking remains to be checked on a device.
